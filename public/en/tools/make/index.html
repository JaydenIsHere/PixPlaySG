What it is

Make is a visual automation tool. You build a "scenario" by linking apps together on a canvas, like a flowchart: when something happens in one app, Make does something in another. It connects to thousands of apps, including Google Sheets, Gmail, Slack, Notion and most social and email tools.

How to use it in your work

Example 1

Never miss an enquiry: form → Google Sheet → instant message

The situation：Enquiries come in from your website form while you're busy. Copying each one into a sheet takes time, and some get missed.

Form→Make→Google Sheets→Chat / Email

Steps

  1. Create a new scenario and add your form app as the first module (the trigger), e.g. Google Forms "Watch responses" or a Webhook from your website form.
  2. Add a Google Sheets "Add a row" module. Click each column and map the matching form field (name, email, message).
  3. Add a message module (Slack, Telegram, Gmail…) and write a short alert using the same fields: "New enquiry from {name}: {message}".
  4. Click "Run once", submit a test form, and check the row and the message arrive.
  5. Turn on scheduling (e.g. every 15 minutes) and save.
✅ Result：Every enquiry is saved in one sheet and you're notified within minutes, with no copy-pasting.

💡 Tip：Add a Filter between modules (e.g. only messages containing "quote") so you're only alerted about the ones that matter.

Example 2

Auto-save email attachments to the right folder

The situation：Invoices, receipts and client files arrive by email and end up lost in your inbox.

Gmail / Outlook→Make→Google Drive

Steps

  1. Start with an email module that watches for new emails with attachments (filter by sender or subject, e.g. "invoice").
  2. Add an Iterator so each attachment is handled one by one.
  3. Add a Google Drive "Upload a file" module and choose the folder. Use the email date in the file name.
  4. Run once with a test email, then schedule it.
✅ Result：Every attachment lands in the right folder with a clear name, ready for accounting or the client.

💡 Tip：Use a Router to send invoices to one folder and contracts to another.

Example 3

One content idea → posted to several places

The situation：You write a post, then copy it into each platform by hand.

Google Sheets→Make→Social / Email

Steps

  1. Keep a sheet with columns: Date, Text, Image link, Status.
  2. Start the scenario with Google Sheets "Watch rows" (or "Search rows" for rows marked Ready).
  3. Add modules for each place you publish or notify (a social app, your email tool, a team chat).
  4. Finish with a Google Sheets "Update a row" module that sets Status to Posted.
  5. Test with one row before you schedule it.
✅ Result：Writing happens in one sheet; publishing happens by itself, and the sheet shows what's done.

💡 Tip：Platforms have rules about automated posting. Keep volume sensible and reply to comments yourself.
